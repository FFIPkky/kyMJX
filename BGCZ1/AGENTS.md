# AGENTS.md

本仓库用于整理 AI 作图指令、买家秀穿搭素材指令、鞋类上脚图/静物图/模特图提示词等内容。以后在 Codex 或 GitHub 插件里艾特本仓库时，优先按下面偏好处理，减少重复说明。

## 默认整理方向

- 主题优先围绕：鞋类买家秀、穿搭图、上脚图、静物摆拍、模特半身图。
- 输出内容要适合直接复制到 AI 作图工具里使用。
- 不只给少量示例，默认要“多来点”：每个分类至少 30 条；如果用户说多一点，优先做到 100 条以上。
- 每条指令要避免重复感，动作、场景、镜头、穿搭、道具都要有变化。
- 风格参考：买家秀实拍风、手机随拍、小红书穿搭图、自然光、生活化场景、真实人物比例、轻微抓拍感、不过度精修。

## 默认分类

表格默认按这些分类整理：

1. 模特半身图
2. 静物图
3. 上脚图

如用户新增品类，可以继续追加，例如：全身图、细节特写、开箱图、店铺主图、场景图。

## 默认表格字段

整理成表格时，默认包含以下列：

| 字段 | 说明 |
|---|---|
| 编号 | 如 M01、S01、F01 |
| 图片类型 | 模特半身图 / 静物图 / 上脚图 |
| 场景 | 拍摄地点或背景 |
| 动作/摆放 | 人物动作或鞋子摆放方式 |
| 镜头/构图 | 拍摄角度、画幅、主体位置 |
| 穿搭/道具 | 服装、袜子、包、杂志、鞋盒等元素 |
| 风格关键词 | 买家秀实拍、手机随拍、自然光等 |
| 反向词 | 需要避免的问题 |
| 最终指令 | 最后一列，必须是可直接复制使用的完整指令 |

重要：最后一列必须叫“最终指令”，并且要把前面拆分字段组合成完整句子，方便直接复制。

## WPS / Excel 偏好

用户通常需要 WPS 能打开的文件，默认提供：

- `.xlsx`：优先格式，适合 WPS 表格 / Excel 打开。
- `.csv`：备用通用格式，避免兼容问题。

如果通过 GitHub 保存，优先保存 CSV，因为 GitHub 预览和下载都方便；如果在本地工作区生成文件，优先同时生成 `.xlsx` 和 `.csv`。

## 指令写法偏好

最终指令建议结构：

```text
图片类型，场景，动作/摆放，镜头/构图，穿搭/道具，风格关键词，鞋子细节清晰，真实买家秀照片，避免反向词
```

示例：

```text
模特半身图，浅色客厅沙发边，坐在沙发边一只腿自然前伸一只手撑沙发，半身到鞋子构图手机竖拍，短裙白袜运动鞋居家穿搭，买家秀实拍风自然光小红书穿搭图轻微抓拍感，鞋子细节清晰，真实买家秀照片，避免影楼感过度精修鞋子变形文字水印多人重复
```

## 常用反向词

默认反向词可以组合使用：

- 影楼感
- 过度摆拍
- 过度精修
- 夸张滤镜
- 畸形手脚
- AI感强
- 鞋子变形
- 鞋头扭曲
- 鞋底变形
- 脚踝变形
- 脸部崩坏
- 镜子变形
- 文字水印
- logo乱码
- 多人重复
- 画面杂乱

- 如果用户要求“整理进仓库”，直接创建或更新对应文件，不要只在聊天里回复。

# 买家秀穿搭 AI 指令资料库

本仓库用于整理本次对话里生成的“买家秀穿搭”AI 作图指令，重点是鞋类穿搭图的随机场景、动作、镜头和最终可复制指令。

## 内容分类

- 模特半身图：人物穿搭、坐姿、蹲姿、街拍、镜子自拍等。
- 静物图：鞋子摆拍、黑布/白布/沙发/石面/鞋盒等场景。
- 上脚图：只拍腿和鞋、第一视角、沙发上脚、楼梯上脚、街头走路抓拍等。

## 表格字段

CSV 文件字段按这个逻辑整理：

| 字段 | 说明 |
|---|---|
| 编号 | 指令编号，例如 M01、S01、F01 |
| 图片类型 | 模特半身图 / 静物图 / 上脚图 |
| 场景 | 拍摄地点或背景 |
| 动作/摆放 | 人物动作或鞋子摆放方式 |
| 镜头/构图 | 拍摄角度、画幅、主体位置 |
| 穿搭/道具 | 服装、袜子、包、杂志、鞋盒等搭配元素 |
| 风格关键词 | 买家秀实拍、手机随拍、自然光等风格词 |
| 反向词 | 需要避免的问题 |
| 最终指令 | 可直接复制到 AI 作图工具里的完整指令 |

## 使用方式

优先复制 CSV 最后一列“最终指令”。如果想让图片不重复，可以随机替换其中的“场景、动作/摆放、镜头/构图、穿搭/道具”。

通用风格方向：买家秀实拍风、手机随拍、小红书穿搭图、自然光、生活化场景、真实人物比例、轻微抓拍感、不过度精修。

通用反向词：影楼感、过度摆拍、夸张滤镜、畸形手脚、AI感强、鞋子变形、文字水印、logo乱码。
